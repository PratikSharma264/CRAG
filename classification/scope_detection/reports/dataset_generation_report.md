# Dataset Generation Report

## Scope Detection Dataset for Pediatric Diabetes RAG

**Project:** Diabetes RAG for children and adolescents
**Task:** 3-class classification of user questions to determine if they fall within system scope before retrieval
**Labels:** 0=OUT_OF_SCOPE, 1=IN_SCOPE, 2=NEEDS_CLARIFICATION

---

## 1. How Rows Were Produced

### 1.1 Original Hand-Written Lists (Source of Truth)
The primary source of truth was the `reserve/original_fragments/` directory containing:
- `in_scope_original.jsonl` (885 rows) - Hand-written IN_SCOPE questions with explicit pediatric age/context
- `out_of_scope_original.jsonl` (915 rows) - Hand-written OUT_OF_SCOPE questions with explicit adult age, non-diabetes medical, or non-medical topics

These were written directly as literal strings in generation scripts (no regex transformation).

### 1.2 Reserve Files (Secondary Sources)
Additional reserve files in `reserve/` provided supplementary rows:
- `in_scope_fragments.jsonl`, `out_scope_fragments.jsonl` - Fragment questions
- `in_scope_no_context.jsonl` - Questions needing context review
- `in_scope_reserve_01-03.jsonl`, `out_of_scope_reserve_01-02.jsonl` - Additional curated rows

### 1.3 Active Files (Previously Generated)
Active generation files (`in_scope_01-11.jsonl`, `out_of_scope_01-12.jsonl`) contained mixed content including reserve rows and duplicates. These were used but with lower priority than originals.

### 1.4 Untrusted NL Rewrite Files (Excluded)
Files with `_nl_` suffix (`in_scope_nl_*.jsonl`, `out_of_scope_nl_*.jsonl`) were generated by a regex rewriting script that:
- Added "My child has..." prefixes to OUT_OF_SCOPE rows (133 rows flagged)
- Removed age context from IN_SCOPE rows
- Lost diabetes-specific terminology
- **All 3,247 NL rows were dropped** during pool building

### 1.5 Rewrite-Flagged Rows (Excluded)
The `reserve/rewrite_flagged/` directory contained 133 rows explicitly flagged for label-determining fact changes. All were excluded.

### 1.6 Blocklist (Excluded)
15 rows in `blocklist_relabel_candidates.jsonl` - pediatric non-diabetes questions with diabetes keywords that must never be restored to OUT_OF_SCOPE or relabeled to IN_SCOPE.

### 1.7 Needs Clarification (Written by Hand)
567 rows written directly as literal strings across 5 files (`needs_clarification_01-05.jsonl`), covering:
- Missing age/population questions
- Unclear patient context ("a patient", "someone")
- Mixed pediatric+adult comparisons
- Ambiguous terminology ("juvenile diabetes", "young adult")
- Bare pronoun follow-ups ("what about at night?")

**Label Conflict Repair (2026-11-16):** During audit, 69 rows in needs_clarification files were found containing pediatric population words (child, teen, adolescent, pediatric, etc.) but labeled NEEDS_CLARIFICATION. Per guidelines, explicit pediatric population = IN_SCOPE. After review: 20 rows relabeled to IN_SCOPE (moved to `in_scope_relabeled_from_clarification.jsonl`), 49 kept as NEEDS_CLARIFICATION (mixed scope, age boundary meta-questions, bare follow-ups, pregnancy, unclear context). Updated needs_clarification files now total 547 rows; relabeled file has 20 rows.

## 2. Class Definitions

### IN_SCOPE (Label 1)
Questions **clearly about diabetes in children or adolescents** (ages 0-18, plus transition-age 19-25 with explicit childhood-onset or transition context).

Positive indicators:
- Explicit age ≤ 18
- Population context: "my son/daughter", "student", "school", "puberty"
- Transition context: "transition to adult care", "childhood-onset T1D"
- Pediatric-specific guidelines: "ISPAD", "pediatric endocrinologist"

### OUT_OF_SCOPE (Label 0)
Questions **clearly outside** the supported domain:
- Adult diabetes (stated age ≥ 19, no childhood-onset/transition context)
- Non-diabetes medical (pediatric or adult)
- Non-medical topics (programming, history, economics, sports)
- Diabetes-adjacent but non-clinical (history of insulin, market size, building apps)

### NEEDS_CLARIFICATION (Label 2)
**Genuinely ambiguous** questions:
- No age/population stated ("What is ideal HbA1c?")
- Unclear patient reference ("A patient with diabetes...")
- Mixed scope ("Compare children and adults with T1D")
- Ambiguous terms ("juvenile diabetes", "young patients")
- Bare pronoun follow-ups with no content

## 3. Boundary Cases (Per Annotation Guidelines)

| Case | Decision | Rationale |
|------|----------|-----------|
| Age ≤ 18 | IN_SCOPE | ISPAD standard; 18 is pediatric |
| Age ≥ 19, no transition context | OUT_OF_SCOPE | Adult diabetes |
| Age 19-25 WITH childhood-onset/transition | IN_SCOPE | Pediatric continuum |
| "Young adult" no age | NEEDS_CLARIFICATION | Ambiguous 18-30 range |
| "Juvenile diabetes" | NEEDS_CLARIFICATION | Dated/ambiguous term |
| Person asking about own diabetes | OUT only if adulthood clear ("mom") | Otherwise NEEDS_CLARIFICATION |
| Strong pediatric context (school, "my son") | IN_SCOPE | Context carries pediatric signal |
| Bare pronoun follow-ups | NEEDS_CLARIFICATION | Classifier sees only this question |

## 4. Exclusions Applied (with Reasons)

| Exclusion Rule | Rows Dropped | Reason |
|----------------|-------------|--------|
| Blocklist/flagged rows | 269 | Explicitly marked as problematic |
| OUT rows with "My child has..." prefix | ~100 | Rewrite artifact adding pediatric context to adult rows |
| Content fragments (<4 words) | ~20 | Not real questions |
| Obscure jargon (FHIR, GATT, pricing codes) | ~15 | No real user would ask |
| IN rows with age ≥19 lacking transition context | ~36 | Violates boundary rules |
| OUT "living with diabetes" rows without adult signal | 62 | Sent to needs_clarification candidates |
| Exact duplicates (conflicting labels) | 4 | Both dropped |
| Near-duplicates (TF-IDF cosine ≥0.8) | 192 | Kept one per family |

## 7. Known Limitations

1. **Labels written by LLM with no human review** - All annotations are synthetic; no expert clinician validation
2. **Style differs between classes** - IN_SCOPE and OUT_OF_SCOPE rows are mostly short topic-style phrases while NEEDS_CLARIFICATION rows are mostly full questions, so class style differs
3. **Some categories are thin** - e.g., `monofilament`, `GAD7_T1D` have only 1-2 rows
4. **Dataset has not been used to train or evaluate any model** - No performance metrics available
5. **NEEDS_CLARIFICATION class is large** (740 rows) - Many are template-generated bare pronoun follow-ups which may not reflect real user behavior
6. **No validation against real user queries** - Distribution may not match production traffic
7. **Age boundary at 18/19 creates artificial split** - Real users near boundary may be misclassified
8. **Transition-age (19-25) rows are sparse** - Only ~20 rows with explicit childhood-onset/transition context
9. **IN/OUT rows state ages/roles; CLARIF rows often fragments** — IN_SCOPE and OUT_OF_SCOPE rows predominantly contain explicit age or role statements (e.g., "10-year-old", "my son", "47-year-old"), while NEEDS_CLARIFICATION rows are frequently short fragments or bare pronoun follow-ups without explicit population signals, creating a style confound that models may exploit.

**This dataset is NOT ready for fine-tuning** without human review and validation.
